# NotationForDummies

A very bare-bones musical editor which is more likely a test how far Gloss can be pushed.

## Install

First, install cabal (Instructions are given for Fedora Workstation but cabal works on almost all distros), one of haskell's package managers.

```bash
sudo dnf install cabal
cabal update
cabal install gloss
```

Then, clone this repo.

```bash
git clone https://github.com/tanIsOnGithub/NotationForDummies
cd NotationForDummies
```

After installation, use cabal to start the program
```bash
cabal run
```
